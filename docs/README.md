# Documentation map

All project documentation is English and limited to 5,000 English words per file. Start with the section that matches your task rather than loading every document into an Agent context.

## Learn and operate

- [Tutorials](tutorials/README.md): guided end-to-end exercises once a usable feature exists.
- [How-to guides](how-to/README.md): development, verification, configuration, and operating procedures.
- [Reference](reference/README.md): commands, platform support, configuration, formats, and interfaces.
- [Explanation](explanation/README.md): architecture, capability boundaries, and design rationale.

## Decisions

- [Architecture decision records](adr/README.md): significant choices, alternatives, consequences, and superseding decisions.

## Contribution rules

Root `AGENTS.md` controls Agent-authored work. Root `CONTRIBUTING.md` describes the pull-request workflow, and root `SECURITY.md` defines the security boundary. This index and each section index must link new documents so automated orphan checks can discover them.
